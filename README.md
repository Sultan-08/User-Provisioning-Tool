# User Provisioning Tool

A simple Linux-based automation project for bulk user account management using Bash scripting.

## 📌 Project Overview

This project helps system administrators automate user account creation and deletion in Linux systems.

The project contains:

* Bulk user provisioning script
* User deprovisioning script
* User data file

It reduces manual work and makes user management faster and more efficient.

---

## 📂 Project Files

### 1. `Provisioning.sh`

Bash script used to create multiple users automatically from a text file.

#### Features

* Reads usernames from `data.txt`
* Creates users in bulk
* Automates repetitive tasks
* Saves administration time

---

### 2. `Deprovisioning.sh`

Bash script used to remove a particular user from the Linux system.

#### Features

* Removes user by username
* Deletes user account safely
* Useful for user deactivation or cleanup

---

### 3. `data.txt`

Text file containing the list of usernames to be added to the system.

---

## ⚙️ Requirements

* Linux Operating System
* Bash Shell
* Root or sudo privileges
